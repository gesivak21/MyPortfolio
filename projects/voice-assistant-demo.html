Project Demo: Voice Assistant Chatbot

The Voice Assistant Chatbot is a real-time conversational AI application that enables users to interact using natural speech. It combines speech-to-text, large language models, and text-to-speech to deliver a seamless voice-driven experience.

The assistant supports multi-language input, configurable voice output, and secure session-based API key handling. It is optimized for cloud deployment and runs reliably on Render.
