Project Demo: AI Utility Suite (SaaS Platform)

The AI Utility Suite is a full-stack AI-powered SaaS application that provides multiple productivity tools under a single authenticated dashboard. The platform supports meeting transcription and summarization, document summarization, and document-based Q&A using Retrieval-Augmented Generation (RAG).

The system is built with a Streamlit frontend and a FastAPI backend, featuring secure authentication, JWT-based authorization, subscription plans, and usage-based limits.
